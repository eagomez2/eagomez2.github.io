<p>EZplus is a web application for managing audiovisual heritage content. It features a search engine specially designed under the rules of Chilean audiovisual archives for media preservation. Users can access the content and description of an specific item by scanning the unique QR code generated by the software, thus, avoiding physical contact that could degrade the endangered material. The software is currently used by <a href="http://www.bibliotecanacionaldigital.cl/bnd/625/w3-article-174090.html" rel="noopener" target="_blank">Audiovisual Archivo of the National Library of Chile</a> (Santiago, Chile) and <a href="http://www.archivodeculturatradicional.cl/" rel="noopener" target="_blank">Patricia Chavarría Traditional Culture Archive</a> (Concepción, Chile). Some features it includes are:</p>
<ul>
<li>Media search engine with different filters related with location, type, category, sub-categories, among others.</li>
<li>Function for importing/exporting search results in Excel documents for offline inspection.</li>
<li>Automatically generated statistics according to media, location, amount of digitised minutes of content, among others.</li>
<li>Accounts with different hierarchy for each user.</li>
<li>Virtual basket for batch editing of multiple items.</li>
</ul>
